Bank Account Simulator

* Description:
  This C++ program simulates a basic bank account system, it has four methods that allows the user to:
    - Deposit funds into a bank account
    - Make purchases which are automatically subtracted from the main balance
    - Printing the current balance, this let the user to see how much money is left in the account
    - A method that save each transaction to a file named "transations.txt," which the user can open it

  * Running the program:
    The user can verify the expected output of the program while running by checking "Bank account simulation testing.pdf"
